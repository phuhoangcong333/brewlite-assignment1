# BrewLite

Ứng dụng đặt cà phê không dùng tiền mặt (NestJS + Next.js).

## Yêu cầu
Node.js 20 trở lên, Git

## Chạy dự án
1. Backend:
   - `cd backend`
   - `cp .env.example .env`
   - `npm install`
   - `npm run start:dev` (chạy ở http://localhost:3001)
2. Frontend (mở terminal khác):
   - `cd frontend`
   - `cp .env.example .env.local`
   - `npm install`
   - `npm run dev` (chạy ở http://localhost:3000)
